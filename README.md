# Portafogli

App locale per 2 portafogli. Privacy: i dati restano solo sul dispositivo.

## Contenuto
- `index.html` — app completa
- `manifest.json` — installazione PWA
- `icon-192.png` / `icon-512.png` / `apple-touch-icon.png` / `favicon.png`

## Uso
1. Apri `index.html` nel browser (o pubblica la cartella su GitHub Pages per installarla con icona)
2. Menu ⋮ → imposta nome app e nomi dei due portafogli
3. Esporta backup JSON quando vuoi (puoi salvarlo a mano su Drive)

Nessun account, nessun server, nessun tracciamento.
